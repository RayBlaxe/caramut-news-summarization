# Logo and Icon Directory

Place your logo and icon files here:

## Required Files:
- **logo.png** - Main logo for navigation and footer (recommended size: 300x100px or similar aspect ratio)
- **icon.png** - Browser tab icon/favicon (recommended size: 32x32px, 64x64px, or 512x512px)

## Optional Files:
- **logo.svg** - SVG version of logo for better scalability
- **icon.ico** - Traditional favicon format for older browsers

## Notes:
- The logo should work well on both light and dark backgrounds
- The icon should be simple and recognizable at small sizes
- PNG format is recommended for better quality
